# Activity 7

## Part I: Profile

User controls and state in SwiftUI. A profile screen with:

- Picker (segmented): choose the avatar
- Slider: zoom the avatar
- ColorPicker: avatar background color
- Stepper (new control): age
- Toggle: public or private profile, notifications on or off

The avatars are from DiceBear "Thumbs" (CC0): https://www.dicebear.com/styles/thumbs/

Project: `Profile.xcodeproj`

## Part II: Birthdays

Chapter 2 "Models and Persistence" of Develop in Swift Tutorials (Save data): https://developer.apple.com/tutorials/develop-in-swift/save-data

A list of friends and their birthdays saved with SwiftData, so they are still there when the app is relaunched.

Project: `Birthdays.xcodeproj`

## Run them on a Mac (Xcode 26)

1. `git clone <repo-url>`
2. `open Activity7/Profile.xcodeproj` or `open Activity7/Birthdays.xcodeproj`
3. Pick an iPhone simulator and press Cmd+R.
4. If Xcode asks for signing: target > Signing & Capabilities > choose your Personal Team.
